How to use this app:
  • Chat Sidebar (left): Type commands like search, tag, select, or clear to interact with your folders using natural language. Example: search cache, tag app Adobe.
  • Scan Form: Enter a directory path and depth, then click Scan to analyze disk usage.
  • Legend: Shows available tags (cache, app, os, custom). Click a tag to filter folders.
  • Tree View: Displays your folder structure. Click folder names to select. Tagged folders are color-coded. Use the Tag button to manually tag folders.
  • Selection: Selected folders are highlighted. Use chat commands or click to select.
  • Commands: search <query> (find folders), tag <tag> <query> (tag folders), select <tag|query> (select by tag or name), clear (clear selection).
